# Contributing to Dental Clinic Management System

Thank you for your interest in contributing to this project!

## 🚀 Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/dental.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit: `git commit -m "Add: your feature description"`
6. Push: `git push origin feature/your-feature-name`
7. Create a Pull Request

## 📋 Code Standards

### Python Code Style
- Follow PEP 8 guidelines
- Use meaningful variable names
- Add docstrings to functions and classes
- Maximum line length: 100 characters

### Django Best Practices
- Use Django's built-in features when possible
- Keep business logic in models
- Use serializers for API endpoints
- Write tests for new features

### Git Commit Messages
Use conventional commits format:
- `feat: Add new feature`
- `fix: Fix bug in...`
- `docs: Update documentation`
- `style: Format code`
- `refactor: Restructure code`
- `test: Add tests`
- `chore: Update dependencies`

## 🧪 Testing

Run tests before submitting:
```bash
cd dental_clinic_system
python manage.py test
```

## 📚 Documentation

Update documentation for any changes:
- API changes → Update `API_DOCUMENTATION.md`
- Setup changes → Update `INSTALLATION.md`
- Features → Update `README.md`

## 🐛 Reporting Issues

Include:
- Clear description
- Steps to reproduce
- Expected vs actual behavior
- Screenshots (if applicable)
- Environment details (OS, Python version, etc.)

## 💡 Feature Requests

Describe:
- What problem it solves
- How it should work
- Any alternatives considered

## 📞 Contact

For questions, contact: developer@dental.com
